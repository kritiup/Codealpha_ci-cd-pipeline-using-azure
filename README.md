# DevOps Deployment Dashboard

A dashboard for monitoring a CI/CD pipeline's deployment status — pipeline runs, deployment
history and application logs.

This project is part of my **CodeAlpha internship**. Phase one is the frontend only, built with
React, TypeScript, Vite, Material UI and React Router, running on local mock data. Azure DevOps,
ACR and App Service get wired in later.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:5173.
